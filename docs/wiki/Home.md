# ArcadeTech Tracker

The shop's system of record: customers and their machines, estimates, work orders,
invoices, payments, parts and stock, purchasing, expenses, mileage and the books. These
pages are about using it day to day. Setting up a server is in the repository's
[`deploy/RUNBOOK.md`](https://github.com/digitalunconciousness/ArcadeTech-Tracker/blob/main/deploy/RUNBOOK.md),
and how it's built is in the
[README](https://github.com/digitalunconciousness/ArcadeTech-Tracker#readme).
