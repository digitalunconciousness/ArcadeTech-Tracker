# Questions

**I can't edit an invoice.**
Issued invoices are locked on purpose. Void it, or issue a credit memo: see
[Fixing mistakes](Fixing-Mistakes).

**It wants a reason for the issue date.**
Any invoice dated before today needs one, so a backdated invoice explains itself later.

**I lost my phone, or my authenticator.**
Another owner resets it under [Settings](Settings) → Users, and you set it up again at your
next sign-in. If the only owner is locked out, there's a last-resort step on the server in
the runbook.

**A customer's link doesn't open.**
Links expire, and can be revoked. Make a new one from the estimate, invoice or Statements
page.

**I can't change "Track stock" on a part.**
It's fixed once the part has been ordered, received or used, because it decides where the
part's cost lands in the books. Add a new part and switch the old one off.

**A bank line won't take the match I want.**
Money in matches payments; money out matches expenses, purchase orders, refunds and the
like. A line that's set aside has to be put back before it can be matched, and a
reconciled line is locked: see [The bank](The-Bank).

**A matched record says "changed since reconciled".**
It was edited after its bank line was reconciled. Check the new amount. If the
reconciliation needs redoing, undo the latest reconciliation with a reason.

**Booking a tech twice: does it warn or refuse?**
It warns, unless "refuse" is switched on in [Settings](Settings) → Business.

**Why isn't a consumable in cost of goods?**
Parts the shop doesn't stock are an expense when they're bought, so they aren't counted
again when they're sold. See [The books](The-Books).

**Where's a report as a spreadsheet?**
Every report has a CSV button, and every list on a computer can download its view.
