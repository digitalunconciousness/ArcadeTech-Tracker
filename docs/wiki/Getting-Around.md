# Getting around

The app has six sections:

| Section | Its tabs |
|---|---|
| **Dashboard** | the dashboard |
| **Work** | Work orders, Board, Dispatch, Estimates |
| **Customers** | Customers, Assets |
| **Money** | Invoices, Statements, Payments, Books, Bank, Reports |
| **Parts** | Parts, Links, Buying, Price book |
| **Settings** | settings (owners only) |

- **On a phone** the sections sit across the top, with a row of tabs under them.
- **On a computer** (a window 1024 px wide or more) they're in a sidebar. Lists open a
  record beside them (split view).
- **Your desktop look:** Ledger (light), Graphite (dark), follow the system, or synthwave.
  Pick it under your name → Desktop look. Phones always use synthwave.

## Command bar and shortcuts

On a computer, press **Ctrl K** (or `/`) to search everything or jump to a page.
Shortcuts: `g` then a letter.

| Keys | Goes to |
|---|---|
| `g d` | Dashboard |
| `g w` | Work orders |
| `g o` | Work board |
| `g l` | Dispatch calendar |
| `g e` | Estimates |
| `g c` | Customers |
| `g a` | Assets |
| `g i` | Invoices |
| `g b` | Books |
| `g r` | Reports |
| `g p` | Parts |
| `g s` | Shopping list |
| `n` | New work order |

## Lists

The work order, customer, invoice, part, asset, estimate, payment and purchase order lists
work the same way on a computer:
- **Sort** by any column, **filter**, and choose which **columns** to show.
- **Save a view** for later, and download the view as a **CSV**.
- On work orders, change the **status** or **tech** of several at once.

## Who sees what

| Role | Can do |
|---|---|
| Owner | everything: issuing and voiding invoices, money, settings |
| Tech | work orders, time, parts and estimates; no money figures |
| Viewer | read-only, money included; meant for a bookkeeper or accountant |

Everyone signs in with a password and a code from an authenticator app.
